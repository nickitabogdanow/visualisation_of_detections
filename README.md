# Visualisation of Detections

Веб-приложение для визуализации данных обнаружений из CSV-файлов. Для каждого номера поста строится heatmap: по оси X — время (шаг 10 минут), по оси Y — частота (шаг 10 МГц), в ячейке — количество записей частот.

## Стек

- [FastAPI](https://fastapi.tiangolo.com/) — backend и API
- [Plotly](https://plotly.com/python/) — интерактивные диаграммы
- [Pandas](https://pandas.pydata.org/) — парсинг и обработка CSV

## Быстрый старт

```bash
git clone https://github.com/nickitabogdanow/visualisation_of_detections.git
cd visualisation_of_detections

python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

uvicorn main:app --reload
```

Откройте в браузере: http://127.0.0.1:8000

## Сборка Windows `.exe`

Сборку `.exe` нужно выполнять на Windows:

```bat
build_exe.bat
```

После сборки результат будет в папке `dist/`:

```text
dist/
├── IDFVisualisation.exe
└── data/
```

CSV-файлы не упаковываются внутрь `.exe`. Кладите их во внешнюю папку
`dist/data/`, затем запускайте:

```bat
dist\IDFVisualisation.exe
```

В консоли будет напечатан адрес веб-сервера. Откройте его в браузере.

По умолчанию используется `127.0.0.1:8002`. Порт можно изменить:

```bat
set PORT=8080
dist\IDFVisualisation.exe
```

## Формат CSV

Каждый файл имеет фиксированную шапку:

| Строка | Содержимое |
|--------|------------|
| 1 | `номер поста`, значение |
| 2 | `частота анализа`, значение |
| 3 | `полоса анализа`, значение |
| 4 | `длительность буфера анализа`, значение |
| 5 | `время начала анализа`, значение |
| 6 | пустая |
| 7 | название таблицы |
| 8 | заголовки столбцов |
| 9+ | данные |

Пример (см. `data/sample_post_101.csv`):

```csv
номер поста,101
частота анализа,2400 МГц
полоса анализа,20 МГц
длительность буфера анализа,3600
время начала анализа,2025-06-25 08:00:00

Результаты анализа поста 101
Время,Частота,Мощность
2025-06-25 08:05:00,2410,-45
2025-06-25 08:05:00,2415,-50
```

Парсер автоматически ищет столбцы **времени** и **частоты** по названию (русские и английские варианты: `Время`, `Частота`, `time`, `frequency` и т.д.).

## Использование

### Через веб-интерфейс

1. Положите CSV-файлы в папку `data/` — они подгрузятся при открытии страницы.
2. Или загрузите файлы через форму на главной странице.
3. Выберите **номер поста** и нажмите **Построить**.

### API

| Метод | URL | Описание |
|-------|-----|----------|
| `GET` | `/` | Веб-интерфейс |
| `GET` | `/api/posts` | Список постов из `data/` |
| `GET` | `/api/chart/{post_number}` | Диаграмма для поста (JSON Plotly) |
| `POST` | `/api/upload/chart?post_number=101` | Загрузка CSV и построение диаграммы |

Пример запроса:

```bash
curl http://127.0.0.1:8000/api/chart/101
```
