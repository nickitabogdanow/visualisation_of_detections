# Инструкция по запуску через `.exe`

1. Откройте папку с приложением.

2. Положите CSV-файлы в папку `data`.

   Папка `data` должна лежать рядом с файлом `IDFVisualisation.exe`.

3. Запустите файл `IDFVisualisation.exe`.

4. В окне консоли появится адрес, например:

   ```text
   http://127.0.0.1:8002
   ```

5. Откройте этот адрес в браузере.

6. В веб-интерфейсе выберите номер поста и нажмите **Построить**.

Чтобы остановить приложение, закройте окно консоли или нажмите `Ctrl+C`.
